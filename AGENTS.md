# Tuyan Tashan preview

This is an independent preview snapshot of the public Apache-2.0 Tuyan repository.
Read `UPSTREAM.json`, `README.md` and `SYNC.md` before changing it.

- Changes belong only to this preview repository and its own named containers,
  data volumes, OSS buckets, and subdomain configuration.
- Do not change Tashan organization settings, other projects, shared deployment
  scripts, host runtimes, or the Hangzhou production repository and services.
- Never copy production accounts, database contents, attachments, or credentials.
- Keep credentials out of Git and images; use GitHub environment secrets.
- Record API/environment contract changes in `SYNC.md`.
- Mini Program remains paused.
